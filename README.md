# 🚩 Personal CTF Writeups Archive

A self-contained static archive of Capture The Flag (CTF) challenge writeups, full technical methodologies, working exploit scripts, reverse engineering steps, and root-cause analyses.

## ✨ Features

- **24 Verified Writeups** across 8 CTF competitions
- **Categories:** Web, Crypto, Forensics, Reverse Engineering, Pwn, Mobile, OSINT, AI-ML, and Misc
- **100% Client-side:** Single-file static architecture with client-side hash routing (`#/` and `#/w/<id>`)
- **Interactive UI:**
  - Real-time instant search across challenges, events, categories, and flags
  - One-click copy buttons on all code blocks and flags with visual feedback
  - Sticky sidebar navigation grouped by challenge category
  - On-Page Table of Contents (TOC) with scroll-spy

## 🚀 Deployment

Configured for immediate zero-config deployment on **Vercel** or **GitHub Pages**.
Simply point your static host to `index.html`.
